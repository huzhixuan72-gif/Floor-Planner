## Floor Planner — AI Floor Plan Platform

- **Website:** https://floor-planner.ai/
- **Category:** AI Design Tools / Architecture / CAD
- **License:** Proprietary (web app, free tier available)

### What it does

All-in-one online floor planning platform combining four capabilities:

- 🤖 **AI floor plan generation** — describe a space in plain language and get a proportional plan with straight walls in under 30 seconds.
- ✏️ **AI region editing** — upload an existing drawing, circle an area, describe the change; everything outside the selection stays pixel-perfect.
- 📐 **Manual editor** — drag walls, place doors/windows/furniture, manage layers, export production-ready drawings.
- 🔄 **Image → CAD conversion** — turn floor plan images into DXF/DWG vectors for AutoCAD and downstream contractor workflows.

### Why it's different

Most tools only generate, only draw, or only convert CAD. Floor Planner runs the whole chain (generate → edit → refine → export) in one browser tab — no installs, no sign-up, no credit card.

### Use cases

Homeowners, interior designers, real estate marketers, architects, contractors, students.
